# unt-rates

This template should help get you started with running api.

## Recommended IDE Setup

[VS Code](https://code.visualstudio.com/) + [python]

## Customize configuration

```sh
pip install flask
```

## Project Setup

```sh
pip install flask
pip install markupsafe
```

### Compile and Run

```sh
flask --app .\main.py run 
```

### Include UI Static files

In order to include static UI files in flask server, reference web README on how to build and copy files to static directory.
